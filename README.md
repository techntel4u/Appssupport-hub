# Apprenticeship Central: e-track Support Hub

The central place for help with e-track (Tribal Maytas Hub) at City of Wolverhampton College.

| Tab | Page | For |
| --- | --- | --- |
| What is e-track? | `index.html` | Everyone: what e-track is, how to log in, key terms |
| Assessor Guides | `assessor-guides.html` | 12 step-by-step guides for assessors |
| Apprentice Guide | `apprentice-guide.html` | Plain-English guide to share with apprentices |
| Employer Guide | `employer-guide.html` | Coming soon |

## Editing

- Plain HTML, CSS and JavaScript. No build step.
- Styles: `assets/style.css` (colours at the top, taken from the e-track session deck).
- Screenshots: `assets/img/`. Click-to-enlarge works on any `<a class="zoom">` around an image.
- To add a guide, copy a `<section class="card task">` block, give it a new `id`, and add a matching tile to the board at the top of the page.

## Publishing

Settings → Pages → Deploy from a branch → `main` / root.
